# Agent rules

1. **Always consult the original source code** in `D:\hungnm\github\OpenMausBot` before designing or implementing a feature, and follow its behavior and structure unless there is a documented reason to differ.
2. **Consult the reference UI** running at <http://localhost:5199/> for layout, styling and interactions before building or changing any screen.
3. **Before every push to git, review `README.md`, `README_VI.md`, `install.ps1` and `install.sh` and update them when the changes affect their content.** That includes a new or changed feature, service, port, environment variable, command or script (`pnpm`/`start.bat`), folder layout, or prerequisite (a tool, runtime or dependency the install scripts must put on a new computer). Update both `README.md` and `README_VI.md` together so the English and Vietnamese instructions describe the same current behavior, and keep their language-switch links working. Update the install scripts when installation requirements change. If no update is needed, explicitly say so in the commit or reply. Complete this review and any required updates before pushing.
4. **Every change to the web app (`web/`) must support both English and Vietnamese.** Write each text the person sees (JSX text, `placeholder`, `title`, `aria-label`, error and status messages, date and number formats) in English through `t("...")` or `<T>...</T>` (`tn(...)` for plurals), add its Vietnamese text to `web/lib/i18n/messages/vi.ts`, and run `pnpm test:web` (`scripts/check-i18n.mjs` fails on a text with no Vietnamese). Never hard-code English in the UI; texts held in a table of labels are shown with `t(label)`. See `docs/phase-8-vietnamese-ui.md` section 10.
